📜 Règlement du Labo

  1. Les membres pronostiquent avant l’heure de début du match. Un pronostic verrouillé ne peut plus être modifié après le coup d’envoi.
  2. Les résultats officiels sont saisis uniquement par le compte administrateur autorisé. Les membres ne peuvent ni modifier ni clôturer un score officiel.
  3. Barème actuellement appliqué par la fonction Supabase : 3 points pour le bon résultat (1 / Nul / 2) et 2 points supplémentaires pour le score exact. Les champs « les deux équipes marquent » et « buteurs » sont conservés comme pronostics complémentaires, mais ne rapportent pas de points tant que le calcul serveur n’a pas été étendu.
  4. Les classements hebdomadaires et mensuels sont calculés à partir des points attribués aux pronostics évalués durant la période. Le classement annuel couvre la période du 1er janvier au 30 novembre.
  5. Le Ticket d’Or est un ticket de jeu doré, pas une coupe ni un Ballon d’Or. Il est attribué le 1er décembre au membre ayant le plus de points sur la période annuelle. En cas d’égalité : meilleur taux de réussite, puis plus grand nombre de pronostics gagnants ; si l’égalité persiste, le gagnant est celui qui a participé au plus grand nombre de matchs évalués.
  6. Le résultat du Ticket d’Or doit être calculé côté serveur et conservé dans l’historique. Une tâche planifiée Supabase doit être activée pour l’attribution automatique annuelle.
  7. Le respect des autres est obligatoire dans le chat. Les messages masqués ne le sont que sur ton appareil ; ils ne sont pas supprimés pour les autres membres.
Ce règlement est un modèle de fonctionnement à valider par le propriétaire du groupe. Le barème doit être identique dans le code serveur Supabase et dans les règles affichées.

🔒 Confidentialité & mentions

Les données de compte sont gérées par Supabase Auth. Le pseudo, les pronostics et les messages servent au fonctionnement du groupe. N’inscris pas d’informations sensibles dans le chat.

Avant toute diffusion publique, complète les mentions légales (éditeur, coordonnées, hébergeur, contact), la politique de confidentialité, les durées de conservation et les modalités d’exercice des droits RGPD. Ce texte est un point de départ et ne remplace pas une vérification juridique adaptée à ton activité.

Données : adresse e-mail pour le compte, pseudo, pronostics, scores et messages. Finalités : authentification, fonctionnement du jeu privé, classements et modération. Droits : pour demander accès, rectification ou suppression, contacte l’administrateur du Labo. Sécurité : les clés secrètes Supabase ne doivent jamais être intégrées au HTML ; seules les clés publiques sont utilisables côté navigateur avec des politiques RLS correctement configurées. Cookies/stockage : le masquage des messages est conservé localement sur l’appareil.
